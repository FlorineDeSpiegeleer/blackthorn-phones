# Blackthorn Projector — A0–A5 prototype

Open via GitHub Pages:

`/blackthorn-phones/projector/`

## Controls
- Right arrow: next step
- Left arrow: previous step
- G: hidden GM panel

## Assets
Put projector images in `projector/assets/` using these filenames:

- guest_suite_getting_ready.png
- grand_stair_arrival.png
- grand_hall_masked_ball.png
- observatory_gallery_night.png
- investigation_scene_wide.png
- grand_hall_side_room.png

If an image is missing, the scene still renders over a dark fallback.

## Scope
This first projector build contains A0–A5 shared story flow, interactive public dialogue, inspection details, and first archive choice. Private romance/dialogue remains on the player phones.

Puzzle boards A7/P1, A10/P2, A11/P3 and A12/P4 are the next projector build step.

Do not put GM-only solution text in this public repo.
